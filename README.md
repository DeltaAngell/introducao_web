# introducao_web
Repositório para projeto da matéria de introdução web da faculdade.

Projeto consiste em criar um site do zero, com ligação à um problema listado nas ODS's.
Utilizando essa premissa, escolhi trabalhar com TailwindCSS e Javascript e criar um site voltado à ODS 13.3: Educação e Conscientização: Melhorar a formação humana e institucional sobre mitigação, adaptação, redução de impactos e alerta precoce; criando um espaço simples e informativo sobre o desmatamento e algumas formas de ajudar no combate e na recuperação de áreas desmatadas.
